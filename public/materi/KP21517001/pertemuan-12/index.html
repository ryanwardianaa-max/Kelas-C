Integrasi Numerik Komposit: Trapesium dan Aturan Simpson

Diferensiasi numerik menaksir laju perubahan dari nilai fungsi diskrit. Pada Bab 7 Rinaldi Munir, nilai-nilai tersebut digunakan untuk menaksir akumulasi atau integral tentu. Interval dibagi menjadi subinterval sama panjang, lalu luas lokal dijumlahkan dengan aturan trapesium, Simpson 1/3, atau Simpson 3/8.

Mata kuliah: Metode Numerik (KP21517001)Dosen: Elis Nurhayati, M.Pd.SKS / Kelas: 3 SKS / Kelas CRujukan: Buku Metode Numerik — Rinaldi Munir, STEI ITB

1. Partisi dan Trapesium Komposit

Kuadratur numerik diperlukan ketika antiturunan sulit diperoleh atau fungsi hanya tersedia sebagai tabel. Interval [a,b] dibagi menjadi n subinterval sama panjang dengan n+1 titik.

Aturan trapesium mengganti grafik pada tiap subinterval dengan garis lurus. Pada bentuk komposit, titik ujung berbobot satu dan semua titik interior berbobot dua.

Galat global berorde O(h^2). Untuk fungsi cembung, garis sekant berada di atas grafik sehingga trapesium cenderung memberi taksiran lebih besar.

Rumus
$$h=\frac{b-a}{n},\quad x_i=a+ih$$
Rumus
$$T_n=\frac{h}{2}\left[f_0+2\sum_{i=1}^{n-1}f_i+f_n\right]$$
Rumus
$$E_T=-\frac{b-a}{12}h^2f''(\xi)=O(h^2)$$
Contoh bertahap

Soal: Hampiri integral x^2 dari 0 sampai 2 dengan trapesium komposit n=4.

  1. h=0{,}5; titiknya 0, 0{,}5, 1, 1{,}5, 2.
  2. Nilai fungsi: 0, 0{,}25, 1, 2{,}25, 4.
  3. T_4=\frac{0{,}5}{2}[0+2(0{,}25+1+2{,}25)+4].
  4. T_4=0{,}25(11)=2{,}75; nilai eksak 8/3\approx2{,}6667.

Jawaban: Hasil trapesium T_4=2{,}75, lebih besar sekitar 0{,}0833 dari nilai eksak.

Hati-hati: n subinterval mempunyai n+1 titik. Jangan memberi bobot dua kepada titik ujung.

2. Simpson 1/3 Komposit

Simpson 1/3 memakai polinom kuadrat melalui tiga titik. Satu panel mencakup dua subinterval, sehingga n harus genap.

Pola bobotnya 1,4,2,4,2,...,4,1. Indeks interior ganjil berbobot empat dan indeks interior genap berbobot dua.

Galat global berorde O(h^4). Aturan ini tepat untuk polinom sampai derajat tiga dan biasanya lebih teliti daripada trapesium pada fungsi cukup halus.

Rumus
$$S_{1/3}=\frac{h}{3}\left[f_0+4\sum_{\substack{i=1\\i\text{ ganjil}}}^{n-1}f_i+2\sum_{\substack{i=2\\i\text{ genap}}}^{n-2}f_i+f_n\right]$$
Rumus
$$E_{1/3}=-\frac{b-a}{180}h^4f^{(4)}(\xi)$$
Rumus
$$n\equiv0\pmod2$$
Contoh bertahap

Soal: Hampiri integral x^2 dari 0 sampai 2 dengan Simpson 1/3 dan n=4.

  1. Gunakan h=0{,}5 dan nilai fungsi 0, 0{,}25, 1, 2{,}25, 4.
  2. Terapkan bobot 1,4,2,4,1.
  3. S_{1/3}=\frac{0{,}5}{3}[0+4(0{,}25)+2(1)+4(2{,}25)+4].
  4. Jumlah berbobot 16, sehingga S_{1/3}=16/6=8/3.

Jawaban: Hasilnya 8/3\approx2{,}6667, tepat karena integran berderajat dua.

Hati-hati: Jangan memakai Simpson 1/3 komposit untuk n ganjil. Ubah partisi atau gabungkan aturan pada sisa interval.

3. Simpson 3/8 Komposit

Simpson 3/8 memakai polinom kubik melalui empat titik. Satu panel mencakup tiga subinterval sehingga n harus kelipatan tiga.

Titik ujung berbobot satu. Indeks interior yang habis dibagi tiga berbobot dua; indeks interior lainnya berbobot tiga. Faktor luarnya adalah 3h/8.

Galat global juga O(h^4) dan aturan tepat sampai polinom derajat tiga. Aturan ini berguna saat jumlah subinterval kelipatan tiga atau tiga subinterval tersisa.

Rumus
$$S_{3/8}=\frac{3h}{8}\left[f_0+3\sum_{\substack{1\le i\le n-1\\i\not\equiv0\ (3)}}f_i+2\sum_{\substack{3\le i\le n-3\\i\equiv0\ (3)}}f_i+f_n\right]$$
Rumus
$$E_{3/8}=-\frac{b-a}{80}h^4f^{(4)}(\xi)$$
Rumus
$$n\equiv0\pmod3$$
Contoh bertahap

Soal: Hampiri integral x^3 dari 0 sampai 3 dengan Simpson 3/8 dan n=3.

  1. h=(3-0)/3=1.
  2. Nilai fungsi pada 0,1,2,3 adalah 0,1,8,27.
  3. S_{3/8}=\frac{3}{8}[0+3(1)+3(8)+27].
  4. Jumlah berbobot 54, maka hasil 162/8=20{,}25.

Jawaban: Hasil Simpson 3/8 adalah 20{,}25, sama dengan nilai eksak 81/4.

Hati-hati: Pada banyak panel, indeks interior kelipatan tiga berbobot dua, bukan tiga. Jangan mengulang pola 1,3,3,1 secara mentah.

4. Pemilihan, Gabungan, dan Pemeriksaan

Trapesium dapat dipakai untuk setiap n positif. Simpson 1/3 memerlukan n genap, sedangkan Simpson 3/8 memerlukan n kelipatan tiga.

Jika n tidak cocok untuk satu aturan Simpson, interval boleh dipisah tanpa tumpang tindih. Untuk n=5, dua subinterval dapat memakai Simpson 1/3 dan tiga sisanya Simpson 3/8.

Periksa jarak seragam, pola bobot, tanda integral, satuan, dan syarat n. Bandingkan hasil n dan 2n untuk melihat konvergensi, tetapi selisih keduanya bukan galat sejati jika nilai eksak belum diketahui.

Rumus
$$I\approx S_{1/3,[x_0,x_2]}+S_{3/8,[x_2,x_5]}$$
Rumus
$$E_a=|I_{2n}-I_n|$$
Rumus
$$p\approx\log_2\left|\frac{I_n-I_{2n}}{I_{2n}-I_{4n}}\right|$$
Contoh bertahap

Soal: Bagaimana memakai Simpson pada enam titik x_0 sampai x_5 yang membentuk lima subinterval?

  1. Lima bukan genap dan bukan kelipatan tiga.
  2. Gunakan Simpson 1/3 pada [x_0,x_2], mencakup dua subinterval.
  3. Gunakan Simpson 3/8 pada [x_2,x_5], mencakup tiga subinterval.
  4. Jumlahkan kedua hasil; x_2 hanya batas bersama, bukan subinterval ganda.

Jawaban: Gunakan gabungan S_{1/3,[x_0,x_2]}+S_{3/8,[x_2,x_5]}.

Hati-hati: Satu rumus komposit standar mengasumsikan h seragam. Untuk data tak seragam, pecah per bagian dan pilih aturan yang sesuai.

Ringkasan

  • Partisi seragam memakai h=(b-a)/n dan n+1 titik.
  • Trapesium berbobot 1,2,\ldots,2,1 dan berorde O(h^2).
  • Simpson 1/3 berpola 1,4,2,\ldots,4,1, memerlukan n genap, berorde O(h^4).
  • Simpson 3/8 memberi bobot dua pada indeks interior kelipatan tiga dan memerlukan n kelipatan tiga.
  • Aturan Simpson dapat digabungkan pada bagian interval yang tidak tumpang tindih.

Latihan Mandiri

  1. Hampiri \int_0^1e^x\,dx dengan trapesium n=4 dan bandingkan dengan e-1.
  2. Hampiri \int_0^1e^x\,dx dengan Simpson 1/3 n=4 dan bandingkan galatnya.
  3. Hampiri \int_0^{\pi/2}\sin x\,dx dengan Simpson 3/8 n=3.
  4. Tuliskan bobot trapesium, Simpson 1/3, dan Simpson 3/8 untuk enam subinterval.
  5. Nyatakan gabungan Simpson untuk lima subinterval dalam f_0,\ldots,f_5.
  6. Untuk f(x)=1/(1+x^2) pada [0,1], bandingkan trapesium dan Simpson 1/3 pada n=2 dan n=4 terhadap \pi/4.
