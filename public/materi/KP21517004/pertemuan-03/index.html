1. Definisi Standar & Kaidah Notasi Buku Bartle

Sesuai koreksi dan arahan dosen, seluruh pembuktian teori himpunan dalam mata kuliah Analisis Real mengacu secara ketat pada Definisi 1.1.3 buku Bartle & Sherbert:

Definisi 1.1.3 Bartle–Sherbert (hlm. 2)
  • (a) Gabungan (Union): \(A \cup B := \{x : x \in A \text{ or } x \in B\}\)
  • (b) Irisan (Intersection): \(A \cap B := \{x : x \in A \text{ and } x \in B\}\)
  • (c) Komplemen Relatif (Selisih): \(A \setminus B := \{x : x \in A \text{ and } x \notin B\}\)

Aturan Penting: Dilarang memakai simbol logika proposisi \(\land, \lor, \neg\). Gunakan kata penghubung alami matematis "dan", "atau", serta simbol keanggotaan murni \(\in\) dan \(\notin\).

2. Teorema 1.1.4 Bartle–Sherbert (Hukum De Morgan untuk Selisih)

Pernyataan Teorema 1.1.4

Jika \(A, B,\) dan \(C\) adalah himpunan sembarang, maka:

$$\begin{aligned} \text{(a)}\quad A \setminus (B \cup C) &= (A \setminus B) \cap (A \setminus C) \\ \text{(b)}\quad A \setminus (B \cap C) &= (A \setminus B) \cup (A \setminus C) \end{aligned}$$

3. Pembuktian Teorema 1.1.4 (a) — Metode Inklusi Ganda (Double Inclusion)

Untuk membuktikan kesamaan dua himpunan \(X = Y\), kita membuktikan dua arah inklusi secara terpisah sesuai buku Bartle:

Bagian 1: Buktikan \(A \setminus (B \cup C) \subseteq (A \setminus B) \cap (A \setminus C)\)
$$\begin{aligned} &\text{Ambil sembarang } x \in A \setminus (B \cup C). \\ &\implies x \in A \text{ dan } x \notin (B \cup C) && \text{[Definisi selisih]} \\ &\implies x \in A \text{ dan } (x \notin B \text{ dan } x \notin C) && \text{[Definisi gabungan]} \\ &\implies (x \in A \text{ dan } x \notin B) \text{ dan } (x \in A \text{ dan } x \notin C) && \text{[Hukum distributif]} \\ &\implies x \in (A \setminus B) \text{ dan } x \in (A \setminus C) && \text{[Definisi selisih]} \\ &\implies x \in (A \setminus B) \cap (A \setminus C) && \text{[Definisi irisan]} \\ &\text{Maka terbukti } A \setminus (B \cup C) \subseteq (A \setminus B) \cap (A \setminus C) \quad \dots (1) \end{aligned}$$
Bagian 2: Buktikan \((A \setminus B) \cap (A \setminus C) \subseteq A \setminus (B \cup C)\)
$$\begin{aligned} &\text{Ambil sembarang } x \in (A \setminus B) \cap (A \setminus C). \\ &\implies x \in (A \setminus B) \text{ dan } x \in (A \setminus C) && \text{[Definisi irisan]} \\ &\implies (x \in A \text{ dan } x \notin B) \text{ dan } (x \in A \text{ dan } x \notin C) && \text{[Definisi selisih]} \\ &\implies x \in A \text{ dan } (x \notin B \text{ dan } x \notin C) && \text{[Hukum distributif]} \\ &\implies x \in A \text{ dan } x \notin (B \cup C) && \text{[Definisi gabungan]} \\ &\implies x \in A \setminus (B \cup C) && \text{[Definisi selisih]} \\ &\text{Maka terbukti } (A \setminus B) \cap (A \setminus C) \subseteq A \setminus (B \cup C) \quad \dots (2) \end{aligned}$$

• Dari (1) dan (2), terbukti sah bahwa \(A \setminus (B \cup C) = (A \setminus B) \cap (A \setminus C)\). \(\blacksquare\)

4. Pembuktian Teorema 1.1.4 (b) — Rantai Ekuivalensi Notasi Pembentuk Himpunan

Pembuktian \(A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)\)
$$\begin{aligned} A \setminus (B \cap C) &:= \{ x \mid x \in A \text{ dan } x \notin (B \cap C) \} && \text{[Definisi selisih]} \\ &:= \{ x \mid x \in A \text{ dan } (x \notin B \text{ atau } x \notin C) \} && \text{[Definisi irisan \& De Morgan]} \\ &:= \{ x \mid (x \in A \text{ dan } x \notin B) \text{ atau } (x \in A \text{ dan } x \notin C) \} && \text{[Hukum distributif]} \\ &:= \{ x \mid x \in (A \setminus B) \text{ atau } x \in (A \setminus C) \} && \text{[Definisi selisih]} \\ &:= (A \setminus B) \cup (A \setminus C) && \text{[Definisi gabungan]} \end{aligned}$$

• Kesimpulan : Terbukti \(A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)\). \(\blacksquare\)

5. Pembahasan Soal Whiteboard Dosen: \(A \cap B = A \setminus (A \setminus B)\)

Manipulasi Identitas Himpunan Kosong (\(A \setminus A = \emptyset\))
$$\begin{aligned} A \cap B &= (A \cap B) \cup (A \setminus A) && \text{[Karena } A \setminus A = \emptyset\text{]} \\ &:= \{ x \mid (x \in A \text{ dan } x \in B) \text{ atau } (x \in A \text{ dan } x \notin A) \} && \text{[Definisi gabungan \& selisih]} \\ &:= \{ x \mid x \in A \text{ dan } (x \in B \text{ atau } x \notin A) \} && \text{[Hukum distributif]} \\ &:= \{ x \mid x \in A \text{ dan } x \notin (A \setminus B) \} && \text{[Hukum De Morgan]} \\ &:= \{ x \mid x \in A \setminus (A \setminus B) \} && \text{[Definisi selisih]} \\ &:= A \setminus (A \setminus B) \end{aligned}$$

• Kesimpulan : Terbukti \(A \cap B = A \setminus (A \setminus B)\). \(\blacksquare\)
