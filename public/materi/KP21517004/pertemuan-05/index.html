1. Pembahasan Latihan Section 1.2 Nomor 1 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

Misalkan \(P(n)\) adalah pernyataan matematika di atas, atau himpunan kebenaran \(S := \{n \in \mathbb{N} : P(n) \text{ benar}\}\).

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = \frac{1}{1(1+1)} = \frac{1}{2}, \qquad \text{Ruas Kanan} = \frac{1}{1+1} = \frac{1}{2}\]

    Karena Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar (yaitu \(1 \in S\)). Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan bahwa pernyataan benar untuk suatu bilangan asli \(n = k\), yaitu \(k \in S\):

    \[\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{k(k+1)} = \frac{k}{k+1}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(P(k+1)\) juga benar, yaitu:

    \[\frac{1}{1\cdot 2} + \cdots + \frac{1}{k(k+1)} + \frac{1}{(k+1)(k+2)} = \frac{k+1}{(k+1)+1} = \frac{k+1}{k+2}\]

    Bukti Aljabar: Mulai dari ruas kiri:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[\frac{1}{1\cdot 2} + \cdots + \frac{1}{k(k+1)}\right] + \frac{1}{(k+1)(k+2)} \\ &= \frac{k}{k+1} + \frac{1}{(k+1)(k+2)} \quad &&\text{[Gunakan Hipotesis Induksi]} \\ &= \frac{k(k+2) + 1}{(k+1)(k+2)} \quad &&\text{[Samakan Penyebut]} \\ &= \frac{k^2 + 2k + 1}{(k+1)(k+2)} \quad &&\text{[Ekspansi Pembilang]} \\ &= \frac{(k+1)^2}{(k+1)(k+2)} \quad &&\text{[Faktorkan Bentuk Kuadrat]} \\ &= \frac{k+1}{k+2} = \text{Ruas Kanan} \quad &&\text{[Sederhanakan faktor } (k+1) \ne 0\text{]} \end{aligned}\]

    Dengan demikian, jika \(k \in S\), maka \(k+1 \in S\).

  4. Kesimpulan:

    Berdasarkan Prinsip Induksi Matematika (Teorema 1.2.2 Bartle), \(S = \mathbb{N}\). Maka rumus terbukti berlaku untuk setiap bilangan asli \(n \in \mathbb{N}\). \(\square\)

2. Pembahasan Latihan Section 1.2 Nomor 2 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[1^3 + 2^3 + \cdots + n^3 = \left[\frac{1}{2}n(n+1)\right]^2\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

Misalkan \(P(n)\) adalah pernyataan di atas, atau himpunan kebenaran \(S := \left\{n \in \mathbb{N} : \sum_{i=1}^n i^3 = \left[\frac{1}{2}n(n+1)\right]^2\right\}\).

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = 1^3 = 1, \qquad \text{Ruas Kanan} = \left[\frac{1}{2}(1)(1+1)\right]^2 = \left[\frac{1}{2}(2)\right]^2 = 1^2 = 1\]

    Karena Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar (\(1 \in S\)). Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan bahwa pernyataan benar untuk suatu bilangan asli \(n = k\), yaitu \(k \in S\):

    \[1^3 + 2^3 + \cdots + k^3 = \left[\frac{1}{2}k(k+1)\right]^2 = \frac{k^2(k+1)^2}{4}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(P(k+1)\) juga bernilai benar, yaitu:

    \[1^3 + 2^3 + \cdots + k^3 + (k+1)^3 = \left[\frac{1}{2}(k+1)((k+1)+1)\right]^2 = \frac{(k+1)^2(k+2)^2}{4}\]

    Bukti Aljabar: Mulai dari ruas kiri dengan menyisipkan hipotesis induksi:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[1^3 + 2^3 + \cdots + k^3\right] + (k+1)^3 \\ &= \frac{k^2(k+1)^2}{4} + (k+1)^3 \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= (k+1)^2 \left[ \frac{k^2}{4} + (k+1) \right] \quad &&\text{[Faktorkan keluar suku } (k+1)^2\text{]} \\ &= (k+1)^2 \left[ \frac{k^2 + 4(k+1)}{4} \right] \quad &&\text{[Samakan penyebut dalam kurung]} \\ &= (k+1)^2 \left[ \frac{k^2 + 4k + 4}{4} \right] \quad &&\text{[Ekspansi bentuk aljabar]} \\ &= (k+1)^2 \left[ \frac{(k+2)^2}{4} \right] \quad &&\text{[Faktorisasi kuadrat sempurna: } k^2+4k+4 = (k+2)^2\text{]} \\ &= \frac{(k+1)^2(k+2)^2}{4} \\ &= \left[\frac{1}{2}(k+1)(k+2)\right]^2 = \text{Ruas Kanan} \end{aligned}\]

    Dengan demikian, terbukti bahwa jika \(k \in S\), maka \(k+1 \in S\).

  4. Kesimpulan:

    Berdasarkan Prinsip Induksi Matematika (Teorema 1.2.2 Bartle), \(S = \mathbb{N}\). Maka rumus berlaku untuk semua bilangan asli \(n \in \mathbb{N}\). \(\square\)

3. Pembahasan Latihan Section 1.2 Nomor 3 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[3 + 11 + \cdots + (8n - 5) = 4n^2 - n\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = 8(1) - 5 = 3, \qquad \text{Ruas Kanan} = 4(1)^2 - 1 = 4 - 1 = 3\]

    Karena Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar. Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan pernyataan benar untuk suatu \(n = k \in \mathbb{N}\):

    \[3 + 11 + \cdots + (8k - 5) = 4k^2 - k\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan benar untuk \(n = k + 1\), yaitu:

    \[3 + 11 + \cdots + (8k - 5) + [8(k+1) - 5] = 4(k+1)^2 - (k+1)\]

    Bukti Aljabar: Mulai dari ruas kiri:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[3 + 11 + \cdots + (8k - 5)\right] + (8k + 3) \\ &= (4k^2 - k) + (8k + 3) \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= 4k^2 + 7k + 3 \\ &= (4k^2 + 8k + 4) - (k + 1) \quad &&\text{[Manipulasi bentuk aljabar]} \\ &= 4(k^2 + 2k + 1) - (k + 1) \\ &= 4(k+1)^2 - (k+1) = \text{Ruas Kanan} \end{aligned}\]

    Maka \(P(k+1)\) terbukti benar.

  4. Kesimpulan:

    Berdasarkan Teorema 1.2.2 Bartle, pernyataan terbukti berlaku untuk setiap \(n \in \mathbb{N}\). \(\square\)

4. Pembahasan Latihan Section 1.2 Nomor 4 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[1^2 + 3^2 + \cdots + (2n - 1)^2 = \frac{4n^3 - n}{3}\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = (2(1) - 1)^2 = 1^2 = 1, \qquad \text{Ruas Kanan} = \frac{4(1)^3 - 1}{3} = \frac{3}{3} = 1\]

    Ruas Kiri = Ruas Kanan, maka \(P(1)\) bernilai benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\):

    \[1^2 + 3^2 + \cdots + (2k - 1)^2 = \frac{4k^3 - k}{3}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan benar untuk \(n = k + 1\), yaitu:

    \[1^2 + 3^2 + \cdots + (2k - 1)^2 + (2(k+1) - 1)^2 = \frac{4(k+1)^3 - (k+1)}{3}\]

    Bukti Aljabar:

    \[\begin{aligned} \text{Ruas Kiri} &= \frac{4k^3 - k}{3} + (2k + 1)^2 \quad &&\text{[Substitusi Hipotesis]} \\ &= \frac{4k^3 - k + 3(4k^2 + 4k + 1)}{3} \quad &&\text{[Samakan Penyebut]} \\ &= \frac{4k^3 - k + 12k^2 + 12k + 3}{3} \\ &= \frac{4k^3 + 12k^2 + 11k + 3}{3} \\ &= \frac{(4k^3 + 12k^2 + 12k + 4) - (k + 1)}{3} \quad &&\text{[Pisahkan suku } -(k+1)\text{]} \\ &= \frac{4(k^3 + 3k^2 + 3k + 1) - (k + 1)}{3} \\ &= \frac{4(k+1)^3 - (k+1)}{3} = \text{Ruas Kanan} \end{aligned}\]

    Maka \(P(k+1)\) terbukti benar.

  4. Kesimpulan:

    Rumus terbukti berlaku untuk setiap bilangan asli \(n \in \mathbb{N}\). \(\square\)

5. Pembahasan Latihan Section 1.2 Nomor 5 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[1^2 - 2^2 + 3^2 + \cdots + (-1)^{n+1}n^2 = \frac{(-1)^{n+1}n(n+1)}{2}\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = (-1)^{1+1}(1^2) = 1, \qquad \text{Ruas Kanan} = \frac{(-1)^{1+1}(1)(2)}{2} = 1\]

    Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\):

    \[\sum_{i=1}^k (-1)^{i+1}i^2 = \frac{(-1)^{k+1}k(k+1)}{2}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan benar untuk \(n = k + 1\), yaitu:

    \[\sum_{i=1}^{k+1} (-1)^{i+1}i^2 = \frac{(-1)^{k+2}(k+1)(k+2)}{2}\]

    Bukti Aljabar:

    \[\begin{aligned} \text{Ruas Kiri} &= \frac{(-1)^{k+1}k(k+1)}{2} + (-1)^{k+2}(k+1)^2 \quad &&\text{[Substitusi Hipotesis]} \\ &= (-1)^{k+2}(k+1) \left[ -\frac{k}{2} + (k+1) \right] \quad &&\text{[Faktorkan } (-1)^{k+2}(k+1)\text{]} \\ &= (-1)^{k+2}(k+1) \left[ \frac{-k + 2k + 2}{2} \right] \\ &= (-1)^{k+2}(k+1) \left[ \frac{k+2}{2} \right] \\ &= \frac{(-1)^{(k+1)+1}(k+1)((k+1)+1)}{2} = \text{Ruas Kanan} \end{aligned}\]

    Maka \(P(k+1)\) terbukti benar.

  4. Kesimpulan:

    Rumus terbukti berlaku untuk setiap bilangan asli \(n \in \mathbb{N}\). \(\square\)

6. Pembahasan Latihan Section 1.2 Nomor 6 (Bartle)

Soal: Buktikan bahwa \(n^3 + 5n\) habis dibagi \(6\) untuk setiap bilangan asli \(n \in \mathbb{N}\).

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[1^3 + 5(1) = 1 + 5 = 6 = 6(1)\]

    Karena \(6\) habis dibagi \(6\), maka \(P(1)\) benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\), yaitu \(k^3 + 5k = 6m\) untuk suatu bilangan bulat positif \(m \in \mathbb{N}\).

  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \((k+1)^3 + 5(k+1)\) juga habis dibagi \(6\).

    Bukti Aljabar: Ekspansi bentuk untuk \(n = k + 1\):

    \[\begin{aligned} (k+1)^3 + 5(k+1) &= (k^3 + 3k^2 + 3k + 1) + (5k + 5) \\ &= (k^3 + 5k) + 3k^2 + 3k + 6 \\ &= (k^3 + 5k) + 3k(k+1) + 6 \\ &= 6m + 3k(k+1) + 6 \quad &&\text{[Substitusi Hipotesis } k^3 + 5k = 6m\text{]} \end{aligned}\]

    Perhatikan suku \(k(k+1)\): karena \(k\) dan \(k+1\) adalah dua bilangan asli berurutan, salah satunya pasti merupakan bilangan genap (kelipatan 2). Dengan demikian, \(k(k+1) = 2p\) untuk suatu \(p \in \mathbb{N}\).

    \[3k(k+1) = 3(2p) = 6p\]

    Substitusikan kembali ke persamaan awal:

    \[(k+1)^3 + 5(k+1) = 6m + 6p + 6 = 6(m + p + 1)\]

    Karena \((m + p + 1) \in \mathbb{N}\), maka \((k+1)^3 + 5(k+1)\) terbukti habis dibagi \(6\).

  4. Kesimpulan:

    Pernyataan terbukti benar bahwa \(n^3 + 5n\) habis dibagi \(6\) untuk setiap \(n \in \mathbb{N}\). \(\square\)

💡 Solusi Super Cepat dengan Aritmatika Modulo (\(\pmod 6\)):
\[n^3 + 5n \equiv n^3 - n + 6n \equiv n^3 - n \equiv n(n^2 - 1) \equiv (n-1)n(n+1) \pmod 6\]

Karena \((n-1), n, (n+1)\) adalah tiga bilangan bulat berurutan, salah satunya pasti kelipatan 3 dan minimal satu genap (kelipatan 2). Maka hasil kalinya pasti kelipatan \(2 \times 3 = 6 \equiv 0 \pmod 6\). Terbukti habis dibagi 6!

7. Pembahasan Latihan Section 1.2 Nomor 7 (Bartle)

Soal: Buktikan bahwa \(5^{2n} - 1\) habis dibagi \(8\) untuk setiap bilangan asli \(n \in \mathbb{N}\).

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[5^{2(1)} - 1 = 5^2 - 1 = 25 - 1 = 24 = 8(3)\]

    Karena \(24\) habis dibagi \(8\), maka \(P(1)\) benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\), yaitu \(5^{2k} - 1 = 8m\) untuk suatu \(m \in \mathbb{N}\), yang berarti \(5^{2k} = 8m + 1\).

  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(5^{2(k+1)} - 1\) juga habis dibagi \(8\).

    Bukti Aljabar:

    \[\begin{aligned} 5^{2(k+1)} - 1 &= 5^{2k+2} - 1 \\ &= 5^2 \cdot 5^{2k} - 1 \\ &= 25 \cdot 5^{2k} - 1 \\ &= 25(8m + 1) - 1 \quad &&\text{[Substitusi Hipotesis } 5^{2k} = 8m + 1\text{]} \\ &= 25(8m) + 25 - 1 \\ &= 8(25m) + 24 \\ &= 8(25m + 3) \end{aligned}\]

    Karena \((25m + 3) \in \mathbb{N}\), maka \(5^{2(k+1)} - 1\) terbukti merupakan kelipatan \(8\) (habis dibagi \(8\)).

  4. Kesimpulan:

    Pernyataan terbukti benar bahwa \(5^{2n} - 1\) habis dibagi \(8\) untuk setiap \(n \in \mathbb{N}\). \(\square\)

💡 Solusi Elegan dengan Aritmatika Modulo (\(\pmod 8\)):
\[5^2 = 25 = 3(8) + 1 \equiv 1 \pmod 8\]

Dengan sifat perpangkatan kongruensi modulo untuk setiap \(n \in \mathbb{N}\):

\[5^{2n} = (5^2)^n \equiv 1^n \equiv 1 \pmod 8 \implies 5^{2n} - 1 \equiv 1 - 1 \equiv 0 \pmod 8\]

Bentuk Induksi Modulo:
• Basis (\(n=1\)): \(5^2 - 1 = 24 \equiv 0 \pmod 8\).
• Hipotesis (\(n=k\)): \(5^{2k} \equiv 1 \pmod 8\).
• Langkah (\(n=k+1\)): \(5^{2(k+1)} = 5^{2k} \cdot 5^2 \equiv (1)(1) = 1 \pmod 8 \implies 5^{2(k+1)} - 1 \equiv 0 \pmod 8\). Terbukti!

8. Pembahasan Latihan Section 1.2 Nomor 8 (Bartle)

Soal: Buktikan bahwa \(5^n - 4n - 1\) habis dibagi \(16\) untuk setiap bilangan asli \(n \in \mathbb{N}\).

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[5^1 - 4(1) - 1 = 5 - 4 - 1 = 0 = 16(0)\]

    Karena \(0\) habis dibagi \(16\), maka \(P(1)\) benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\), yaitu \(5^k - 4k - 1 = 16m\) untuk suatu \(m \in \mathbb{Z}_{\ge 0}\), yang berarti \(5^k = 16m + 4k + 1\).

  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(5^{k+1} - 4(k+1) - 1\) juga habis dibagi \(16\).

    Bukti Aljabar:

    \[\begin{aligned} 5^{k+1} - 4(k+1) - 1 &= 5 \cdot 5^k - 4k - 4 - 1 \\ &= 5 \cdot 5^k - 4k - 5 \\ &= 5(16m + 4k + 1) - 4k - 5 \quad &&\text{[Substitusi Hipotesis } 5^k = 16m + 4k + 1\text{]} \\ &= 80m + 20k + 5 - 4k - 5 \\ &= 80m + 16k \\ &= 16(5m + k) \end{aligned}\]

    Karena \((5m + k) \in \mathbb{Z}_{\ge 0}\), maka \(5^{k+1} - 4(k+1) - 1\) terbukti merupakan kelipatan \(16\) (habis dibagi \(16\)).

  4. Kesimpulan:

    Pernyataan terbukti benar bahwa \(5^n - 4n - 1\) habis dibagi \(16\) untuk setiap \(n \in \mathbb{N}\). \(\square\)

💡 Solusi Cepat dengan Induksi Modulo (\(\pmod{16}\)):

• Basis (\(n=1\)): \(5^1 - 4(1) - 1 = 0 \equiv 0 \pmod{16}\).
• Hipotesis (\(n=k\)): Asumsikan \(5^k \equiv 4k + 1 \pmod{16}\).
• Langkah (\(n=k+1\)):

\[5^{k+1} = 5 \cdot 5^k \equiv 5(4k + 1) = 20k + 5 \pmod{16}\]

Karena \(20k = 16k + 4k \equiv 4k \pmod{16}\), maka:

\[5^{k+1} \equiv 4k + 5 = 4(k+1) + 1 \pmod{16} \implies 5^{k+1} - 4(k+1) - 1 \equiv 0 \pmod{16}\]

Bentuk target terpenuhi secara tepat!

9. Pembahasan Latihan Section 1.2 Nomor 9 (Bartle)

Soal: Buktikan bahwa \(n^3 + (n+1)^3 + (n+2)^3\) habis dibagi \(9\) untuk setiap bilangan asli \(n \in \mathbb{N}\).

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

  1. Basis Induksi (\(n = 1\)):
    \[1^3 + (1+1)^3 + (1+2)^3 = 1^3 + 2^3 + 3^3 = 1 + 8 + 27 = 36 = 9(4)\]

    Karena \(36\) habis dibagi \(9\), maka \(P(1)\) benar. Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan pernyataan benar untuk suatu \(n = k \in \mathbb{N}\), yaitu:

    \[k^3 + (k+1)^3 + (k+2)^3 = 9m \quad \text{untuk suatu } m \in \mathbb{N}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa untuk \(n = k + 1\), bentuk berikut juga habis dibagi \(9\):

    \[(k+1)^3 + ((k+1)+1)^3 + ((k+1)+2)^3 = (k+1)^3 + (k+2)^3 + (k+3)^3\]

    Bukti Aljabar: Tinjau selisih bentuk \((k+1)\) dengan bentuk \(k\):

    \[\begin{aligned} &[(k+1)^3 + (k+2)^3 + (k+3)^3] - [k^3 + (k+1)^3 + (k+2)^3] \\ &= (k+3)^3 - k^3 \\ &= (k^3 + 9k^2 + 27k + 27) - k^3 \\ &= 9k^2 + 27k + 27 = 9(k^2 + 3k + 3) \end{aligned}\]

    Dengan memindahkan suku hipotesis ke ruas kanan:

    \[\begin{aligned} (k+1)^3 + (k+2)^3 + (k+3)^3 &= [k^3 + (k+1)^3 + (k+2)^3] + 9(k^2 + 3k + 3) \\ &= 9m + 9(k^2 + 3k + 3) \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= 9(m + k^2 + 3k + 3) \end{aligned}\]

    Karena \((m + k^2 + 3k + 3) \in \mathbb{N}\), maka \((k+1)^3 + (k+2)^3 + (k+3)^3\) terbukti habis dibagi \(9\).

  4. Kesimpulan:

    Terbukti bahwa \(n^3 + (n+1)^3 + (n+2)^3\) habis dibagi \(9\) untuk setiap \(n \in \mathbb{N}\). \(\square\)

💡 Solusi Cepat dengan Induksi Modulo (\(\pmod 9\)):

• Basis (\(n=1\)): \(1^3 + 2^3 + 3^3 = 36 \equiv 0 \pmod 9\).
• Hipotesis (\(n=k\)): Asumsikan \(k^3 + (k+1)^3 + (k+2)^3 \equiv 0 \pmod 9\).
• Langkah (\(n=k+1\)):

\[[(k+1)^3 + (k+2)^3 + (k+3)^3] - [k^3 + (k+1)^3 + (k+2)^3] = (k+3)^3 - k^3\]

Uraikan selisih suku kubik:

\[(k+3)^3 - k^3 = 9k^2 + 27k + 27 = 9(k^2 + 3k + 3) \equiv 0 \pmod 9\]

Maka \((k+1)^3 + (k+2)^3 + (k+3)^3 \equiv 0 + 0 = 0 \pmod 9\). Terbukti habis dibagi 9!

10. Pembahasan Latihan Section 1.2 Nomor 10 (Bartle)

Soal: Buatlah dugaan rumus untuk jumlah \(\frac{1}{1\cdot 3} + \frac{1}{3\cdot 5} + \cdots + \frac{1}{(2n-1)(2n+1)}\), kemudian buktikan dugaan tersebut dengan Induksi Matematika.

Langkah 1: Menemukan Dugaan (Conjecture)

Uji untuk beberapa nilai awal \(n\):

  • Untuk \(n = 1\): \(\frac{1}{1\cdot 3} = \frac{1}{3}\)
  • Untuk \(n = 2\): \(\frac{1}{3} + \frac{1}{3\cdot 5} = \frac{1}{3} + \frac{1}{15} = \frac{5+1}{15} = \frac{6}{15} = \frac{2}{5}\)
  • Untuk \(n = 3\): \(\frac{2}{5} + \frac{1}{5\cdot 7} = \frac{2}{5} + \frac{1}{35} = \frac{14+1}{35} = \frac{15}{35} = \frac{3}{7}\)

Dugaan Rumus: \(\sum_{i=1}^n \frac{1}{(2i-1)(2i+1)} = \frac{n}{2n+1}\) untuk setiap \(n \in \mathbb{N}\).

Langkah 2: Pembuktian Formal dengan Induksi Matematika

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = \frac{1}{1\cdot 3} = \frac{1}{3}, \qquad \text{Ruas Kanan} = \frac{1}{2(1)+1} = \frac{1}{3}\]

    Ruas Kiri = Ruas Kanan, maka basis terbukti benar.

  2. Hipotesis Induksi:

    Diasumsikan dugaan benar untuk suatu \(n = k \in \mathbb{N}\):

    \[\sum_{i=1}^k \frac{1}{(2i-1)(2i+1)} = \frac{k}{2k+1}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan benar untuk \(n = k + 1\), yaitu:

    \[\sum_{i=1}^{k+1} \frac{1}{(2i-1)(2i+1)} = \frac{k+1}{2(k+1)+1} = \frac{k+1}{2k+3}\]

    Bukti Aljabar: Mulai dari ruas kiri:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[\sum_{i=1}^k \frac{1}{(2i-1)(2i+1)}\right] + \frac{1}{(2(k+1)-1)(2(k+1)+1)} \\ &= \frac{k}{2k+1} + \frac{1}{(2k+1)(2k+3)} \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= \frac{k(2k+3) + 1}{(2k+1)(2k+3)} \quad &&\text{[Samakan Penyebut]} \\ &= \frac{2k^2 + 3k + 1}{(2k+1)(2k+3)} \quad &&\text{[Ekspansi Bentuk Aljabar Pembilang]} \\ &= \frac{(2k+1)(k+1)}{(2k+1)(2k+3)} \quad &&\text{[Faktorkan: } 2k^2+3k+1 = (2k+1)(k+1)\text{]} \\ &= \frac{k+1}{2k+3} \quad &&\text{[Bagi pembilang dan penyebut dengan } (2k+1) \ne 0\text{]} \\ &= \frac{k+1}{2(k+1)+1} = \text{Ruas Kanan} \end{aligned}\]

    Langkah induksi terbukti benar.

  4. Kesimpulan:

    Berdasarkan Prinsip Induksi Matematika, dugaan rumus \(\frac{n}{2n+1}\) terbukti benar untuk setiap bilangan asli \(n \in \mathbb{N}\). \(\square\)

11. Pembahasan Latihan Section 1.2 Nomor 11 (Bartle)

Soal: Buatlah dugaan rumus untuk jumlah \(n\) bilangan ganjil positif pertama \(1 + 3 + \cdots + (2n-1)\), kemudian buktikan dengan Induksi Matematika.

Langkah 1: Menemukan Dugaan (Conjecture)

  • Untuk \(n = 1\): \(1 = 1 = 1^2\)
  • Untuk \(n = 2\): \(1 + 3 = 4 = 2^2\)
  • Untuk \(n = 3\): \(1 + 3 + 5 = 9 = 3^2\)
  • Untuk \(n = 4\): \(1 + 3 + 5 + 7 = 16 = 4^2\)

Dugaan Rumus: \(1 + 3 + \cdots + (2n-1) = n^2\) untuk setiap \(n \in \mathbb{N}\).

Langkah 2: Pembuktian Formal dengan Induksi Matematika

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = 2(1) - 1 = 1, \qquad \text{Ruas Kanan} = 1^2 = 1\]

    Ruas Kiri = Ruas Kanan, maka basis terbukti benar.

  2. Hipotesis Induksi:

    Diasumsikan benar untuk \(n = k\):

    \[1 + 3 + \cdots + (2k - 1) = k^2\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan benar untuk \(n = k + 1\), yaitu:

    \[1 + 3 + \cdots + (2k - 1) + (2(k+1) - 1) = (k+1)^2\]

    Bukti Aljabar:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[1 + 3 + \cdots + (2k - 1)\right] + (2k + 1) \\ &= k^2 + (2k + 1) \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= k^2 + 2k + 1 \\ &= (k+1)^2 = \text{Ruas Kanan} \quad &&\text{[Faktorisasi Kuadrat Sempurna]} \end{aligned}\]
  4. Kesimpulan:

    Terbukti bahwa jumlah \(n\) bilangan ganjil pertama adalah \(n^2\) untuk setiap \(n \in \mathbb{N}\). \(\square\)

12. Sifat Aljabar di ℝ (Section 2.1 Bartle)

⚠️ Aturan Baku Pengoperasian (Bu Linda): Saat membuktikan atau mengoperasikan langkah aljabar, jangan menyebutkan nama sifat (seperti komutatif, asosiatif, identitas, dll.). Cukup sebutkan kode sifatnya saja: (A1), (A2), (A3), (A4), (M1), (M2), (M3), (M4), atau (D).

Sistem bilangan real \((\mathbb{R}, +, \cdot)\) memenuhi sembilan sifat aljabar dasar:

Sifat Penjumlahan (A1–A4)

  • (A1)
    \[\forall a, b \in \mathbb{R} \ni a + b = b + a\]
  • (A2)
    \[\forall a, b, c \in \mathbb{R} \ni (a + b) + c = a + (b + c)\]
  • (A3)
    \[\forall a \in \mathbb{R},\; \exists 0 \in \mathbb{R} \ni 0 + a = a \text{ dan } a + 0 = a\]
  • (A4)
    \[\forall a \in \mathbb{R},\; \exists -a \in \mathbb{R} \ni a + (-a) = 0 \text{ dan } (-a) + a = 0\]

Sifat Perkalian (M1–M4)

  • (M1)
    \[\forall a, b \in \mathbb{R} \ni a \cdot b = b \cdot a\]
  • (M2)
    \[\forall a, b, c \in \mathbb{R} \ni (a \cdot b) \cdot c = a \cdot (b \cdot c)\]
  • (M3)
    \[\forall a \in \mathbb{R},\; \exists 1 \in \mathbb{R} \ni 1 \cdot a = a \text{ dan } a \cdot 1 = a\]
  • (M4)
    \[\forall a \in \mathbb{R} \text{ dengan } a \ne 0,\; \exists \frac{1}{a} \in \mathbb{R} \ni a \cdot \left(\frac{1}{a}\right) = 1 \text{ dan } \left(\frac{1}{a}\right) \cdot a = 1\]

Sifat Distributif (D)

\[\forall a, b, c \in \mathbb{R} \ni a \cdot (b + c) = (a \cdot b) + (a \cdot c) \quad\text{dan}\quad (b + c) \cdot a = (b \cdot a) + (c \cdot a)\]

4. Teorema Ketunggalan dan Perkalian Nol (Bartle 2.1.2–2.1.4)

  • Teorema 2.1.2 (Ketunggalan):
    • Elemen identitas penjumlahan (\(0\)) dan perkalian (\(1\)) adalah tunggal.
    • Invers penjumlahan (\(-a\)) dan invers perkalian (\(1/a\) untuk \(a \ne 0\)) masing-masing adalah tunggal.
    • Jika \(a + b = a\), maka \(b = 0\). Jika \(b \ne 0\) dan \(a \cdot b = b\), maka \(a = 1\).
  • Teorema 2.1.3:
    (a) \(a \cdot 0 = 0\) untuk setiap \(a \in \mathbb{R}\).
    (b) \((-1) \cdot a = -a\).
    (c) \(-(-a) = a\).
    (d) \((-1) \cdot (-1) = 1\).
  • Teorema 2.1.4 (Pemberangus Perkalian):
    Jika \(a, b \in \mathbb{R}\) dan \(a \cdot b = 0\), maka \(a = 0\) atau \(b = 0\).

5. Bahan Baca: Induksi dari Basis Tertentu dan Contoh (Bartle 1.2.3–1.2.4)

Ini adalah Bahan Baca pelengkap sesuai urutan buku teks Bartle–Sherbert edisi keempat:

1.2.3 Induksi Versi Kedua (Mulai dari n₀)

Untuk \(n_0 \in \mathbb{N}\), jika \(P(n_0)\) benar dan untuk setiap \(k \ge n_0\), \(P(k) \Rightarrow P(k+1)\), maka \(P(n)\) benar untuk semua \(n \ge n_0\).

1.2.4 Contoh-Contoh Penerapan

Pola penerapan pada ketaksamaan (seperti \(2^n > n^2\) untuk \(n \ge 5\)), deret geometri, dan keterbagian aljabar.
