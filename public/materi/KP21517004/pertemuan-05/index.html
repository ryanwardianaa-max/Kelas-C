1. Pembahasan Latihan Section 1.2 Nomor 1 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

Misalkan \(P(n)\) adalah pernyataan matematika di atas, atau himpunan kebenaran \(S := \{n \in \mathbb{N} : P(n) \text{ benar}\}\).

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = \frac{1}{1(1+1)} = \frac{1}{2}, \qquad \text{Ruas Kanan} = \frac{1}{1+1} = \frac{1}{2}\]

    Karena Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar (yaitu \(1 \in S\)). Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan bahwa pernyataan benar untuk suatu bilangan asli \(n = k\), yaitu \(k \in S\):

    \[\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{k(k+1)} = \frac{k}{k+1}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(P(k+1)\) juga benar, yaitu:

    \[\frac{1}{1\cdot 2} + \cdots + \frac{1}{k(k+1)} + \frac{1}{(k+1)(k+2)} = \frac{k+1}{(k+1)+1} = \frac{k+1}{k+2}\]

    Bukti Aljabar: Mulai dari ruas kiri:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[\frac{1}{1\cdot 2} + \cdots + \frac{1}{k(k+1)}\right] + \frac{1}{(k+1)(k+2)} \\ &= \frac{k}{k+1} + \frac{1}{(k+1)(k+2)} \quad &&\text{[Gunakan Hipotesis Induksi]} \\ &= \frac{k(k+2) + 1}{(k+1)(k+2)} \quad &&\text{[Samakan Penyebut]} \\ &= \frac{k^2 + 2k + 1}{(k+1)(k+2)} \quad &&\text{[Ekspansi Pembilang]} \\ &= \frac{(k+1)^2}{(k+1)(k+2)} \quad &&\text{[Faktorkan Bentuk Kuadrat]} \\ &= \frac{k+1}{k+2} = \text{Ruas Kanan} \quad &&\text{[Sederhanakan faktor } (k+1) \ne 0\text{]} \end{aligned}\]

    Dengan demikian, jika \(k \in S\), maka \(k+1 \in S\).

  4. Kesimpulan:

    Berdasarkan Prinsip Induksi Matematika (Teorema 1.2.2 Bartle), \(S = \mathbb{N}\). Maka rumus terbukti berlaku untuk setiap bilangan asli \(n \in \mathbb{N}\). \(\square\)

2. Pembahasan Latihan Section 1.2 Nomor 2 (Bartle)

Soal: Buktikan bahwa untuk setiap \(n \in \mathbb{N}\) berlaku:

\[1^3 + 2^3 + \cdots + n^3 = \left[\frac{1}{2}n(n+1)\right]^2\]

Langkah Pembuktian Formal (Prinsip Induksi 1.2.2)

Misalkan \(P(n)\) adalah pernyataan di atas, atau himpunan kebenaran \(S := \left\{n \in \mathbb{N} : \sum_{i=1}^n i^3 = \left[\frac{1}{2}n(n+1)\right]^2\right\}\).

  1. Basis Induksi (\(n = 1\)):
    \[\text{Ruas Kiri} = 1^3 = 1, \qquad \text{Ruas Kanan} = \left[\frac{1}{2}(1)(1+1)\right]^2 = \left[\frac{1}{2}(2)\right]^2 = 1^2 = 1\]

    Karena Ruas Kiri = Ruas Kanan, maka \(P(1)\) benar (\(1 \in S\)). Syarat basis terpenuhi.

  2. Hipotesis Induksi:

    Diasumsikan bahwa pernyataan benar untuk suatu bilangan asli \(n = k\), yaitu \(k \in S\):

    \[1^3 + 2^3 + \cdots + k^3 = \left[\frac{1}{2}k(k+1)\right]^2 = \frac{k^2(k+1)^2}{4}\]
  3. Langkah Induksi (\(n = k + 1\)):

    Akan dibuktikan bahwa \(P(k+1)\) juga bernilai benar, yaitu:

    \[1^3 + 2^3 + \cdots + k^3 + (k+1)^3 = \left[\frac{1}{2}(k+1)((k+1)+1)\right]^2 = \frac{(k+1)^2(k+2)^2}{4}\]

    Bukti Aljabar: Mulai dari ruas kiri dengan menyisipkan hipotesis induksi:

    \[\begin{aligned} \text{Ruas Kiri} &= \left[1^3 + 2^3 + \cdots + k^3\right] + (k+1)^3 \\ &= \frac{k^2(k+1)^2}{4} + (k+1)^3 \quad &&\text{[Substitusi Hipotesis Induksi]} \\ &= (k+1)^2 \left[ \frac{k^2}{4} + (k+1) \right] \quad &&\text{[Faktorkan keluar suku } (k+1)^2\text{]} \\ &= (k+1)^2 \left[ \frac{k^2 + 4(k+1)}{4} \right] \quad &&\text{[Samakan penyebut dalam kurung]} \\ &= (k+1)^2 \left[ \frac{k^2 + 4k + 4}{4} \right] \quad &&\text{[Ekspansi bentuk aljabar]} \\ &= (k+1)^2 \left[ \frac{(k+2)^2}{4} \right] \quad &&\text{[Faktorisasi kuadrat sempurna: } k^2+4k+4 = (k+2)^2\text{]} \\ &= \frac{(k+1)^2(k+2)^2}{4} \\ &= \left[\frac{1}{2}(k+1)(k+2)\right]^2 = \text{Ruas Kanan} \end{aligned}\]

    Dengan demikian, terbukti bahwa jika \(k \in S\), maka \(k+1 \in S\).

  4. Kesimpulan:

    Berdasarkan Prinsip Induksi Matematika (Teorema 1.2.2 Bartle), \(S = \mathbb{N}\). Maka rumus berlaku untuk semua bilangan asli \(n \in \mathbb{N}\). \(\square\)

4. Sifat Aljabar di ℝ (Section 2.1 Bartle)

Sistem bilangan real \((\mathbb{R}, +, \cdot)\) merupakan sebuah lapangan (field) dengan dua operasi biner penjumlahan (\(+\)) dan perkalian (\(\cdot\)) yang memenuhi sembilan sifat dasar:

Sifat Penjumlahan (A1–A4)

  • (A1) Sifat Komutatif: \(a + b = b + a\) untuk semua \(a, b \in \mathbb{R}\).
  • (A2) Sifat Asosiatif: \((a + b) + c = a + (b + c)\) untuk semua \(a, b, c \in \mathbb{R}\).
  • (A3) Elemen Nol (Identitas Aditif): Terdapat elemen \(0 \in \mathbb{R}\) sehingga \(0 + a = a\) dan \(a + 0 = a\) untuk semua \(a \in \mathbb{R}\).
  • (A4) Elemen Negatif (Invers Aditif): Untuk setiap \(a \in \mathbb{R}\), terdapat elemen \(-a \in \mathbb{R}\) sehingga \(a + (-a) = 0\) dan \((-a) + a = 0\).

Sifat Perkalian (M1–M4)

  • (M1) Sifat Komutatif: \(a \cdot b = b \cdot a\) untuk semua \(a, b \in \mathbb{R}\).
  • (M2) Sifat Asosiatif: \((a \cdot b) \cdot c = a \cdot (b \cdot c)\) untuk semua \(a, b, c \in \mathbb{R}\).
  • (M3) Elemen Satuan (Identitas Multiplikatif): Terdapat elemen \(1 \in \mathbb{R}\) dengan \(1 \ne 0\) sehingga \(1 \cdot a = a\) dan \(a \cdot 1 = a\) untuk semua \(a \in \mathbb{R}\).
  • (M4) Elemen Resiprokal (Invers Multiplikatif): Untuk setiap \(a \in \mathbb{R}\) dengan \(a \ne 0\), terdapat elemen \(1/a \in \mathbb{R}\) sehingga \(a \cdot (1/a) = 1\) dan \((1/a) \cdot a = 1\).

Sifat Distributif (D)

\(a \cdot (b + c) = (a \cdot b) + (a \cdot c)\) dan \((b + c) \cdot a = (b \cdot a) + (c \cdot a)\) untuk semua \(a, b, c \in \mathbb{R}\).

4. Teorema Ketunggalan dan Perkalian Nol (Bartle 2.1.2–2.1.4)

  • Teorema 2.1.2 (Ketunggalan):
    • Elemen identitas penjumlahan (\(0\)) dan perkalian (\(1\)) adalah tunggal.
    • Invers penjumlahan (\(-a\)) dan invers perkalian (\(1/a\) untuk \(a \ne 0\)) masing-masing adalah tunggal.
    • Jika \(a + b = a\), maka \(b = 0\). Jika \(b \ne 0\) dan \(a \cdot b = b\), maka \(a = 1\).
  • Teorema 2.1.3:
    (a) \(a \cdot 0 = 0\) untuk setiap \(a \in \mathbb{R}\).
    (b) \((-1) \cdot a = -a\).
    (c) \(-(-a) = a\).
    (d) \((-1) \cdot (-1) = 1\).
  • Teorema 2.1.4 (Pemberangus Perkalian):
    Jika \(a, b \in \mathbb{R}\) dan \(a \cdot b = 0\), maka \(a = 0\) atau \(b = 0\).

5. Bahan Baca: Induksi dari Basis Tertentu dan Contoh (Bartle 1.2.3–1.2.4)

Ini adalah Bahan Baca pelengkap sesuai urutan buku teks Bartle–Sherbert edisi keempat:

1.2.3 Induksi Versi Kedua (Mulai dari n₀)

Untuk \(n_0 \in \mathbb{N}\), jika \(P(n_0)\) benar dan untuk setiap \(k \ge n_0\), \(P(k) \Rightarrow P(k+1)\), maka \(P(n)\) benar untuk semua \(n \ge n_0\).

1.2.4 Contoh-Contoh Penerapan

Pola penerapan pada ketaksamaan (seperti \(2^n > n^2\) untuk \(n \ge 5\)), deret geometri, dan keterbagian aljabar.
