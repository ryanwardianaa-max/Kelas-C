Fungsi Biaya, Penerimaan, dan Laba

Pertemuan 04 · Kamis, 03 September 2026

Konsep biaya produksi (tetap, variabel, total, rata-rata, marginal), penerimaan total, laba, dan titik impas (BEP).

I. Fungsi Biaya II. Fungsi Penerimaan III. Laba & BEP IV. Contoh Soal V. Latihan

I. Fungsi Biaya

Biaya Total (Total Cost — TC)

TC adalah seluruh biaya yang dikeluarkan untuk memproduksi sejumlah barang. Terdiri dari:

  • Biaya Tetap (Fixed Cost — FC): biaya yang tidak tergantung pada jumlah produksi (sewa, gaji tetap, penyusutan). FC konstan berapapun Q.
  • Biaya Variabel (Variable Cost — VC): biaya yang berubah sesuai jumlah produksi (bahan baku, upah tenaga kerja langsung). VC = f(Q), biasanya naik.
TC = FC + VC

Biaya Rata-rata (Average Cost — AC)

Biaya total per unit barang. Dihitung dengan membagi TC dengan jumlah produksi Q.

AC = TC / Q

AC juga bisa dipecah menjadi:

AC = AFC + AVC

dengan AFC = FC/Q (biaya tetap rata-rata) dan AVC = VC/Q (biaya variabel rata-rata).

Biaya Marginal (Marginal Cost — MC)

Tambahan biaya total akibat menambah produksi satu unit barang.

MC = ΔTC / ΔQ

Jika fungsi TC kontinu, MC adalah turunan TC terhadap Q: MC = dTC/dQ.

MC mencerminkan hukum hasil yang semakin menurun: pada awalnya MC turun (efisiensi), lalu naik setelah kapasitas optimal tercapai.

Bentuk umum fungsi biaya: sering diasumsikan sebagai fungsi kuadrat TC = aQ² + bQ + c dengan c = FC, dan a,b konstanta. Fungsi linier juga sering dipakai: TC = bQ + c.

II. Fungsi Penerimaan (Revenue)

Penerimaan Total (Total Revenue — TR)

Hasil penjualan seluruh barang: harga jual per unit (P) dikali jumlah barang (Q).

TR = P × Q

Jika harga konstan (pasar persaingan sempurna), TR linier: TR = P·Q. Jika harga tergantung Q (monopoli), TR berbentuk fungsi kuadrat: TR = P(Q)·Q.

Penerimaan Rata-rata (Average Revenue — AR)

Penerimaan per unit = harga jual per unit.

AR = TR / Q = P

Jadi AR sama dengan harga.

Penerimaan Marginal (Marginal Revenue — MR)

Tambahan penerimaan akibat menjual satu unit tambahan.

MR = ΔTR / ΔQ

Jika TR kontinu, MR = dTR/dQ. Dalam pasar persaingan sempurna, MR = P (konstan). Dalam monopoli, MR menurun.

III. Laba dan Titik Impas (BEP)

Laba (Profit — π)

Selisih antara penerimaan total dan biaya total.

π = TR - TC

Laba positif jika TR > TC, rugi jika TR < TC, dan impas (BEP) jika TR = TC.

Titik Impas (Break-Even Point — BEP)

Tingkat produksi Q di mana TR = TC, sehingga laba = 0.

BEP dapat dihitung dengan menyelesaikan persamaan:

TR = TC

atau

P × Q = FC + VC(Q)

Dalam kasus linier (TR = P·Q, TC = bQ + c):

P·Q = bQ + c → Q_BEP = c / (P - b)

dengan (P - b) = margin kontribusi per unit.

Catatan: BEP adalah titik minimum agar tidak rugi. Untuk laba tertentu, gunakan π target: TR - TC = π_target.

IV. Contoh Soal

Soal 1. Sebuah perusahaan memiliki biaya tetap FC = 1000 dan biaya variabel VC = 5Q. Harga jual per unit P = 15. Tentukan fungsi biaya total, fungsi penerimaan total, titik impas, dan laba saat Q = 300.

Penyelesaian

  1. Fungsi biaya total: TC = FC + VC = 1000 + 5Q.
  2. Fungsi penerimaan total: TR = P × Q = 15Q.
  3. Titik impas (BEP): TR = TC → 15Q = 1000 + 5Q → 10Q = 1000 → Q_BEP = 100.
  4. Laba saat Q = 300: π = TR - TC = 15(300) - (1000 + 5·300) = 4500 - (1000 + 1500) = 4500 - 2500 = 2000.

Jadi BEP terjadi pada Q = 100 unit; pada Q = 300 laba Rp 2.000.

Soal 2. Diketahui TC = 0,5Q² + 3Q + 200 dan permintaan P = 20 - Q (monopoli). Tentukan TR, MR, MC, dan Q yang memaksimumkan laba.

Penyelesaian

  1. Fungsi TR: TR = P × Q = (20 - Q)Q = 20Q - Q².
  2. Fungsi MR: MR = dTR/dQ = 20 - 2Q.
  3. Fungsi MC: MC = dTC/dQ = Q + 3.
  4. Maksimum laba: syarat MR = MC → 20 - 2Q = Q + 3 → 17 = 3Q → Q = 17/3 ≈ 5,67.
  5. Harga dan laba: P = 20 - 5,67 = 14,33. TC = 0,5(5,67²) + 3(5,67) + 200 ≈ 16,11 + 17,01 + 200 = 233,12. TR = 14,33 × 5,67 ≈ 81,25. π ≈ 81,25 - 233,12 = -151,87 (rugi). Ini menunjukkan biaya tetap terlalu tinggi; perusahaan mungkin tutup jika tidak ada subsidi.

V. Contoh Soal dari Kelas

Alur materi: Biaya tetap dan variabel → biaya total → penerimaan total → laba/rugi → titik impas → perubahan harga → fungsi konsumsi dan tabungan. Urutan ini menghubungkan keputusan perusahaan dengan keputusan rumah tangga.

1. BEP produksi dalam kilogram

Harga jual Rp4.500/kg, biaya tetap Rp102.500, biaya variabel Rp4.000/kg. Berapa produksi minimum agar impas?

Margin kontribusi tiap kg = 4.500 − 4.000 = Rp500.

QBEP = 102.500 / 500 = 205 kg

Artinya, 205 kg menutup seluruh biaya. Di bawah 205 kg rugi; di atasnya laba.

2. Dampak kenaikan harga

FC = Rp30.000, harga awal Rp50/unit, VC = 40% harga, produksi 10.000 unit. Bandingkan dengan harga baru Rp75/unit.

Kondisi awal: VC = 40% × 50 = 20. BEP = 30.000/(50−20) = 1.000 unit. TR = 50×10.000 = 500.000. TC = 30.000 + 20×10.000 = 230.000. Laba = Rp270.000.

Harga baru: VC = 40% × 75 = 30. BEP = 30.000/(75−30) = 666,67, sehingga target aman dibulatkan ke atas menjadi 667 unit. TR = 750.000. TC = 330.000. Laba = Rp420.000.

Kenaikan harga menurunkan BEP dan menaikkan laba, dengan asumsi jumlah permintaan tetap 10.000 unit.

3. Fungsi konsumsi dan tabungan

C = 4,5 + 0,9Yd dan Yd = Rp15.000.000. Sesuai koreksi catatan kelas, 4,5 dipakai langsung, bukan dikonversi menjadi juta.

Identitas pendapatan: Yd = C + S, sehingga S = Yd − C.

S = Yd − (4,5 + 0,9Yd) = 0,1Yd − 4,5

C = 4,5 + 0,9×15.000.000 = 13.500.004,5.

S = 0,1×15.000.000 − 4,5 = 1.499.995,5.

Pemeriksaan: 13.500.004,5 + 1.499.995,5 = 15.000.000.

Catatan satuan: Dalam buku ekonomi, konstanta 4,5 sering berarti Rp4,5 juta. Namun contoh ini mengikuti koreksi Ryan/penjelasan kelas: konstanta 4,5 digunakan langsung. Kalkulator menyediakan pilihan satuan agar kedua interpretasi dapat diperiksa.
