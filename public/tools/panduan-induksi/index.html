Panduan Interaktif Pembuktian Induksi

Bukan mesin pembuat bukti otomatis. Alat ini membantu memastikan setiap bagian bukti hadir dan memperlihatkan hubungan antara hipotesis, suku berikutnya, dan target.

Pilih pola bukti

Pilih jenis induksi yang sesuai dengan tipe soal matematika yang sedang dihadapi:

📌 Kapan Dipakai?

Untuk membuktikan rumus atau deret yang berlaku bagi semua bilangan asli \(n = 1, 2, 3, \dots\) (contoh: rumus deret ganjil, jumlah aritmetika, pecahan teleskopik).

1. PernyataanTulis rumus lengkap yang ingin dibuktikan: \(P(n)\).
2. Basis (n = 1)Hitung kedua ruas untuk \(n=1\) sampai terbukti sama persis.
3. Hipotesis (n = k)Andaikan rumus benar untuk sembarang \(k\in\mathbb N\): asumsikan \(P(k)\) benar.
4. Target (n = k+1)Tulis bentuk rumus target yang harus dicapai: \(P(k+1)\).
5. Jembatan BuktiMulai dari ruas kiri \(P(k+1)\), masukkan hipotesis \(P(k)\), lalu manipulasi aljabar sampai sama dengan target.
6. KesimpulanSimpulkan rumus berlaku untuk semua \(n\in\mathbb N\).
📌 Kapan Dipakai? (Bartle 1.2.3)

Dipakai jika rumus salah pada angka-angka awal (\(n = 1, 2, \dots\)) dan baru benar mulai dari angka tertentu \(n_0\).

Contoh Nyata: Ketaksamaan \(2^n < n!\)
• Untuk \(n=1\): \(2^1 < 1!\) → \(2 < 1\) (Salah)
• Untuk \(n=2\): \(2^2 < 2!\) → \(4 < 2\) (Salah)
• Untuk \(n=3\): \(2^3 < 3!\) → \(8 < 6\) (Salah)
• Untuk \(n=4\): \(2^4 < 4!\) → \(16 < 24\) (Benar! Basis pembuktian mulai dari \(n_0 = 4\)).

Perbedaan dengan Induksi Biasa: Langkah basis dibuktikan pada \(n_0\) (bukan \(n=1\)). Kesimpulan akhirnya menyatakan rumus berlaku untuk semua \(n \ge n_0\).

📌 Kapan Dipakai? (Bartle 1.2.5)

Dipakai jika untuk membuktikan langkah ke-\(k+1\), kita tidak cukup hanya mengandalkan suku ke-\(k\), melainkan membutuhkan bantuan kebenaran dari seluruh kasus sebelumnya (\(1, 2, 3, \dots, k\)).

Contoh Nyata: Teorema Faktorisasi Prima (setiap bilangan asli \(n \ge 2\) adalah bilangan prima atau perkalian prima).
Saat kita ingin membuktikan bilangan \(k+1\) dapat difaktorkan menjadi \(a \cdot b\), kedua faktor \(a\) dan \(b\) nilainya lebih kecil dari \(k+1\) (bukan harus persis \(k\)). Kita butuh jaminan bahwa semua bilangan sebelum \(k+1\) sudah memenuhi sifat tersebut.

Perbedaan dengan Induksi Biasa: Pada hipotesis induksi, kita mengasumsikan \(P(1), P(2), \dots, P(k)\) seluruhnya benar sekaligus.

Periksa jembatan Latihan Induksi

Pilih latihan yang ingin diperiksa langkah jembatannya:

\[\frac{1}{1\cdot 2} + \frac{1}{2\cdot 3} + \cdots + \frac{1}{n(n+1)} = \frac{n}{n+1}\]
\[1^2+3^2+\cdots+(2n-1)^2=\frac{4n^3-n}{3}\]

Batas alat

Pemeriksaan angka hanya membantu memahami pola. Persamaan benar pada beberapa nilai belum membuktikan persamaan benar untuk semua bilangan asli. Bukti formal tetap membutuhkan basis dan jembatan.
