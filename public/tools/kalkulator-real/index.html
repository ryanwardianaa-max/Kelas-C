Modul 1 · Pembukti Formal Limit Epsilon-Delta

Pilih bentuk fungsi, atur koefisien beserta titik c, lalu geser ε — aplikasi merangkai draf, batas, pilihan δ, dan bukti formal yang berakhir Terbukti ∎.

0.10

Fungsi resiprokal tidak punya koefisien — cukup tentukan titik c. Ingat: domain f(x)=1/x adalah x ≠ 0, sehingga c harus c ≠ 0.

Definisi. \(\lim_{x\to c}f(x)=L\) jika untuk setiap \(\varepsilon>0\) ada \(\delta>0\) sehingga untuk semua \(x\): \(0<|x-c|<\delta\Rightarrow|f(x)-L|<\varepsilon\).

    Modul 2 · Penentu Supremum, Infimum, Maksimum & Minimum

    Pilih himpunan preset — interval, barisan diskrit, atau himpunan kuadratik — lalu nilai sup/inf/max/min dihitung disertai pembuktian karakterisasi ε dan Sifat Archimedes.

    Barisan preset tidak memerlukan parameter — analisis langsung dihitung untuk n ∈ ℕ.

    Karakterisasi ε. \(u=\sup S\) jika dan hanya jika (i) \(u\) batas atas \(S\), dan (ii) untuk setiap \(\varepsilon>0\) ada \(s\in S\) dengan \(s>u-\varepsilon\). Sifat Archimedes: untuk setiap \(x\in\mathbb{R}\) ada \(n\in\mathbb{N}\) sehingga \(n>x\).
    ∅

    Modul 3 · Barisan Real & Pencari Indeks Ambang K(ε)

    Hitung indeks asli terkecil K sehingga setiap n ≥ K menjamin |xₙ − L| < ε — lengkap dengan derivasi formal, tabel nilai, dan diagram sebar.

    0.010
    Definisi. \(\lim_{n\to\infty}x_n=L\) jika untuk setiap \(\varepsilon>0\) ada \(K\in\mathbb{N}\) sehingga untuk semua \(n\ge K\) berlaku \(|x_n-L|<\varepsilon\). Keberadaan \(K\) untuk ε sembarang dijamin Sifat Archimedes.
    ∅
